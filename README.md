# 🌾 Sugarcane Data Analysis Project

An Exploratory Data Analysis (EDA) project that analyzes sugarcane production data to discover meaningful insights, trends, and patterns using Python.

---

## 📌 Project Overview

This project focuses on analyzing sugarcane production data through data cleaning, preprocessing, visualization, and statistical exploration. The objective is to understand production trends, identify top-producing regions, and gain insights from the dataset using various visualization techniques.

> **Note:** This project is purely a **Data Analysis (EDA)** project and does not involve Machine Learning models.

---

## 🎯 Objectives

- Clean and preprocess the raw dataset.
- Handle missing and duplicate values.
- Perform exploratory data analysis.
- Analyze sugarcane production across different regions.
- Visualize important trends and relationships.
- Generate meaningful business and agricultural insights.

## 📥 Installation

Clone the repository

```bash
git clone https://github.com/Harikrishnankanjingattu/sugarcane_data_analsysis_project.git
```

Move into the project

```bash
cd sugarcane_data_analsysis_project
```

Install dependencies

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook

```bash
jupyter notebook
```
